# Quick 261105-uy9: on-demand GitLab MR reviewer (`ocr-bench mr <url>`)

Personal tool: paste a GitLab MR link, get a Markdown report of findings and suggestions, copy what is
worth it into the MR by hand. Nothing is posted to GitLab.

## Decisions (user, 2026-11-05)

- Branch `feat/mr-reviewer` from `docs/codebase-map` (the GitLab work is not on `main`).
- Reuse `ocr-bench` (headless pipeline: throwaway Postgres + one sandboxed runner in one container).
- Remove the non-Rust product surface; the Rust crate stays whole because `review` depends on
  `db`, `forge`, `indexer`, `accounts` and `review_archive` depends on `server`.

## Tasks

1. `backend/src/bench/mr.rs`: parse the MR URL, read `GITLAB_TOKEN` (removed from env), GET
   `/api/v4/projects/:path/merge_requests/:iid`, fetch target branch + `refs/merge-requests/:iid/head`
   into `/work/repo` (0700; token only in the git child env via `gitlab::git_auth::apply_at`), write
   `/work/pr/pr.json`, set `RB_*` and run `run_reviewbench` (suggestions on, 60 min deadline), render
   `/output/mr-<iid>/review.md` from `ocr-findings.json`. Unit tests for URL parsing and rendering.
2. `main_bench.rs` subcommand `mr`; `docker/bench-entrypoint.sh` accepts `mr <url>`, appends
   `/run/ocr-ca/ca.crt` to the system bundle, only requires `RB_OUT` for `reviewbench`.
3. `scripts/review-mr.sh` wrapper + `docs/mr-review.md`.
4. Delete frontend, site, web image, nginx, compose deploy files, node config, bench adapters.

## Verify

`cargo fmt --check`, `cargo clippy -D warnings`, `cargo test bench::` via WSL scripts.
