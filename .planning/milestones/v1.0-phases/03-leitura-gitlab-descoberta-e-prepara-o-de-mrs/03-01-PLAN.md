<objective>
Build the GitLab read layer (`glab api` runner, project listing, MR listing and live state) and route the existing `forge::` read functions to it on GitLab deploys.

Purpose: every caller in `server/` and `review/` already calls `forge::list_workspaces`, `forge::list_open_prs`, `forge::live_pr_state`, etc. Defining those names explicitly in `forge/mod.rs` shadows the `pub(crate) use crate::github::*` glob, so GitLab support lands without touching call sites and GitHub stays byte-identical.
Output: `gitlab/{api,projects,mrs}.rs`, `gitlab/read_tests.rs`, dispatch wrappers in `forge/mod.rs`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitLab API -> server | Project paths, branch names, MR titles and JSON shape are untrusted |
| server -> glab subprocess | Endpoint strings built from DB values; env carries host/config dir only |
| server error strings -> HTTP/DB | Errors reach the browser and poll_error columns |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | projects.rs path_with_namespace -> repos_dir path | mitigate | `valid_full_name` drops empty, `.`/`..`, non `[A-Za-z0-9-_.]` segments and mismatched namespace/path before RepoInput is built |
| T-03-02 | Tampering | endpoint building in api.rs/mrs.rs | mitigate | `enc` percent-encodes project path and branch; args passed as an array to `Command`, no shell |
| T-03-03 | Information disclosure | api_at error strings | mitigate | fixed UI-SPEC strings only; stdout/stderr/serde text never returned; `redact` before classify; log line carries only the classify code |
| T-03-04 | Information disclosure | PAT in argv/env | mitigate | glab reads its own config.yml; `apply_glab_env` scrubs token vars; tests assert no `glpat-` in args.log |
| T-03-05 | Denial of service | slow/throttled GitLab | mitigate | 120 s timeout per call, max 3 retries with 1/2/4 s backoff, RwLock readers so polling does not block Settings status |
| T-03-06 | Spoofing | GitHub flow regression via wrappers | mitigate | GitHub arms call the same `crate::github::` fn with the same args; forge tests stay green |
</threat_model>
