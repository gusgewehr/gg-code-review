## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-07 | Elevation of privilege | runner image/services | mitigate | Dockerfile.runner untouched; static check in CI fails if glab/CA/GitLab env reach runner services |

| T-02-10 | Information disclosure | CA mount | accept | CA certificate is public material; mounted read-only, server only |
