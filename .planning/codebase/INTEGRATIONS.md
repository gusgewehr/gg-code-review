# External Integrations

**Analysis Date:** 2026-11-04

## APIs & External Services

**AI providers (run only inside sandboxed runners):**
- Claude Code CLI (`claude --print`) - arguments and tool policy in `backend/src/providers/claude.rs`
  - Host: `api.anthropic.com`
  - Auth: app-managed sign-in projected read-only into runners (`OCR_REVIEW_CLAUDE_AUTH_DIR`, `OCR_RUNNER_AUTH_ROOT`); flows in `backend/src/server/claude_auth.rs`
- Codex CLI (`codex exec`) - `backend/src/providers/codex.rs`
  - Hosts: `chatgpt.com`, `api.openai.com`, `auth.openai.com`
  - Auth: browser sign-in via `backend/src/server/codex_auth.rs`; callback redirects to 127.0.0.1:1455 (forwarded to container port 1456, `OCR_CODEX_CALLBACK_BIND`)
- Models and efforts listed in `backend/src/providers/engines.rs`
- Egress allowlist: `PROVIDER_HOSTS` in `backend/src/sandbox/egress.rs`; runners reach it only through the `review-egress` proxy (`OCR_RUNNER_PROXY=http://review-egress:8790`)
- Accounts, plan usage, token-only usage: `backend/src/accounts/`, `backend/src/server/usage_http.rs`

**Source hosting:**
- GitHub via the authenticated `gh` CLI (`backend/src/github/`, auth in `backend/src/github/auth.rs`); no app-managed tokens
  - Auth: `gh` config, `GH_TOKEN`/`GITHUB_TOKEN` only as development fallback; `OCR_GH_HOST` for GitHub Enterprise hosts
- GitLab: not integrated in code (only incidental mentions in tests); a GitLab provider layer via `glab` is a fork goal in user memory, not present at this commit

## Data Storage

**Databases:**
- Postgres 17 (`docker-compose.yml`, service `postgres`)
  - Connection: `OCR_DATABASE_URL_FILE` (app role), `OCR_DATABASE_RO_URL_FILE`, `OCR_DATABASE_OWNER_URL_FILE` (migrations); passwords generated by `database-secret` service
  - Client: `postgres` + `r2d2_postgres` pool (`backend/src/db/pg/pool.rs`), migrations in `backend/src/db/pg/*.sql` via `backend/src/db/pg/migrate.rs`; roles created by `docker/postgres/init-roles.sh`
  - Test: `OCR_TEST_DATABASE_URL`
- SQLite: legacy import only (`backend/src/db/schema.sql`, `ocr-server import-sqlite`)

**File Storage:**
- Docker volumes `ocr-data` (repos under `OCR_REPOS_DIR=/data/repos`, config) and `postgres-data`; frozen review archives in `backend/src/review_archive/`

**Caching:**
- None (Cargo/pnpm build caches only)

## Authentication & Identity

**Auth Provider:**
- Custom. Browser API calls are guarded by `OCR_API_TOKEN` (`backend/src/server/http.rs`; web image injects it into `VITE_OCR_API_TOKEN` placeholder via `docker/web-entrypoint.sh`)
- AI sign-in: Claude and Codex flows above; GitHub via `gh`

## Monitoring & Observability

**Error Tracking:**
- None

**Logs:**
- Docker `json-file` driver with rotation (`docker-compose.yml`); `OCR_REVIEW_DEBUG_DIR` optional debug output; Server-Sent stream in `backend/src/server/stream.rs`

## CI/CD & Deployment

**Hosting:**
- Self-hosted Compose; images on GHCR (`ghcr.io/bridglabs/opencodereview-*`)

**CI Pipeline:**
- GitHub Actions in `.github/workflows/`: `ci.yml`, `docker-smoke.yml`, `audit.yml`, `changelog.yml`, `cla.yml`, `pr-title.yml`, `provider-cli-canary.yml`, `release.yml`, `site.yml` (actions pinned to commit SHAs)
- Smoke: `docker/runner-smoke.py` (fake inference), `docker/provider-cli-canary.py`

## Environment Configuration

**Required env vars:**
- `OCR_BIND`, `OCR_DATA_DIR`, `OCR_DATABASE_*_URL_FILE`, `OCR_REPOS_DIR`, `OCR_REVIEW_RUNNER_DIR`, `OCR_WEB_APP_URL`, `OCR_API_TOKEN`; optional `OCR_GH_HOST`, `OCR_REVIEW_RUNNERS`, `OCR_POLL_INTERVAL_SECONDS`, `OCR_AUTO_REINDEX`
- `OCR_DIAGNOSTIC_*` variables gate paid real-review diagnostics (`docker/run-real-review-diagnostic.py`); require maintainer authorization

**Secrets location:**
- `database-secret` Docker volume; AI credentials in app-managed auth volumes; `.env` files are never committed

## Webhooks & Callbacks

**Incoming:**
- No GitHub webhooks; pull requests are discovered by polling (`backend/src/server/polling.rs`, `OCR_POLL_INTERVAL_SECONDS` default 300)
- Codex OAuth callback on 127.0.0.1:1455

**Outgoing:**
- Review comments, status comments and publication to GitHub PRs through `gh` (`backend/src/server/publication.rs`, `status_comments.rs`)
- Benchmark adapters in `bench/adapters/` (ReviewBench, Martian, AACR-Bench) run via `ocr-bench` and `docker/Dockerfile.bench`
