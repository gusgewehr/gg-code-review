## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output -> GitLab note body | untrusted model text becomes markdown GitLab parses for quick actions and references |
| server -> glab subprocess | token and body must not cross via argv |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Elevation of privilege | sanitize::finalize_body | mitigate | leading "/"+letter gets ZWSP on every line (including fences) so /merge, /approve, /assign never execute |
| T-04-02 | Spoofing/Repudiation (mention spam, cross-references) | sanitize::finalize_body | mitigate | ZWSP after @ # ! ~ % $ & outside code; unit test per sigil |
| T-04-03 | Information disclosure | write::api_write_at | mitigate | body only in 0600 temp file via --input; fixed error strings; test asserts args.log has no body or glpat- |
| T-04-04 | Tampering (duplicate writes) | write::api_write_at | mitigate | POST not retried on 5xx/timeout; only 429 |
| T-04-05 | Denial of service | sanitize truncation | accept | 1,000,000-char cap; a proxy with a lower limit surfaces as a generic write error |
</threat_model>
