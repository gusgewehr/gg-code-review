<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model findings -> GitLab discussions | untrusted text and model-chosen path/line become writes on the MR |
| GitLab API responses -> server | note lists and versions decide what is skipped and which SHAs are used |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-09 | Elevation of privilege | publish::post_review_at | mitigate | event ignored; only discussions/notes endpoints; test asserts no approve/merge argv |
| T-04-10 | Tampering (stale positions) | publish::post_review_at | mitigate | live MR sha + versions[0].head_commit_sha must equal reviewed head before any write and before the summary |
| T-04-11 | Tampering (duplicates) | publish / notes | mitigate | fingerprint and summary-marker skip from a fail-closed listing; summary posted last; POST not retried on 5xx |
| T-04-12 | Spoofing (marker adoption from other users) | GitLabStatusComments | mitigate | status ownership requires author.id == publisher_id (existing owned_comment_generations filter) |
| T-04-13 | Information disclosure | notes/publish errors | mitigate | fixed error strings only, bodies via --input temp file, never body/stderr in Err or logs |
| T-04-14 | Elevation of privilege (quick actions) | all write bodies | mitigate | note_json / discussion body use finalize_body; test asserts /merge arrives neutralised |
</threat_model>
