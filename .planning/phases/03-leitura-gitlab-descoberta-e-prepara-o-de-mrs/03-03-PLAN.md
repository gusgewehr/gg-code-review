<objective>
Make review preparation work for GitLab MRs: git transport auth to the GitLab host, fail-closed handling of GitHub-only `gh` calls, and nested `grupo/sub/projeto` identity accepted by the frozen-evidence scope and DB helper.

Purpose: REV-01/02/03 already hold in the existing flow (`review/git.rs` fetches `forge::current().pr_head_ref(n)` = `refs/merge-requests/<iid>/head`, `resolve_base_rev` fetches the target branch, merge-base and diff are local git, a fetched SHA that differs from the live API SHA fails with "PR head changed before review preparation"). What blocks GitLab is git auth, GitHub-only steps reached during preparation, and the two-segment check. Fork MRs work because the MR ref lives in the target project; no fork remote is ever added.
Output: `gitlab/git_auth.rs`, generalized base64 helper, forge auth wrapper, transport guard, skips in frozen.rs/retention.rs, loosened Scope::validate, rsplit_once.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server git child -> GitLab host | Credentialed HTTPS fetch |
| glab config.yml -> server memory | Token read per git call |
| repository identity -> archive/filesystem paths | Scope.repository joins archive and dependency paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-09 | Information disclosure | token in git argv/logs | mitigate | token only in `GIT_CONFIG_VALUE_0` env of the git child; test asserts `get_args()` empty; no eprintln of the value; `GIT_TERMINAL_PROMPT=0` |
| T-03-10 | Information disclosure | runners receiving host creds | mitigate | auth applied only in server-side git builders; runner IPC unchanged; `docker/test-gitlab-isolation.py` must keep passing |
| T-03-11 | Elevation of privilege | fork MR adding remotes/creds | mitigate | only `origin` (target project) is fetched; `refs/merge-requests/<iid>/head`; no `git remote add` |
| T-03-12 | Tampering | Scope.repository traversal | mitigate | per-segment checks kept (`.`/`..`/empty/charset), 256 cap; tests for `g/../x`, `a//b` |
| T-03-13 | Spoofing | gh calls against github.com on a GitLab deploy | mitigate | `require_github` in transport fails closed before spawning gh |
| T-03-14 | Tampering | lagging MR ref vs API sha | accept | existing mismatch check fails preparation ("PR head changed...") and the next poll retries |
