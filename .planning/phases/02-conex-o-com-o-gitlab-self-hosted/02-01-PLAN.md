<objective>
Backend boot for a GitLab deploy: select the forge from env, pin it in the settings table and refuse to start on a change (FORGE-01), add `Forge::GitLab` with non-panicking "not supported yet" behavior for GitHub-only work, and build the internal-CA trust bundle for server child processes (AUTH-04).

Purpose: every later GitLab feature reads `forge::current()`/`forge::host()` and relies on glab/git trusting the internal CA.
Output: `forge/guard.rs`, `gitlab/{mod,ca}.rs`, boot wiring in `server/mod.rs`, gating of GitHub-only workers.
</objective>
